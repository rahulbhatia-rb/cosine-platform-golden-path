# 30 / 60 / 90 Day Platform Roadmap

## First 30 days
- map clusters, deploy paths, network boundaries, secrets, and current incidents
- establish service inventory and owners
- define baseline SLOs
- add release visibility and rollback runbooks
- identify top developer-experience friction

## By 60 days
- golden-path Helm chart
- GitOps promotion flow
- cluster/node autoscaling policy
- standard OTel instrumentation
- SLO burn-rate alerts
- workload identity and secret-manager baseline
- preview environment pattern

## By 90 days
- progressive delivery with automatic promotion/rollback
- multi-cluster fleet lifecycle and upgrade policy
- customer-managed/on-prem release bundle
- signed SBOM + provenance
- disaster-recovery game day
- cost/capacity dashboards
- platform scorecard per service
